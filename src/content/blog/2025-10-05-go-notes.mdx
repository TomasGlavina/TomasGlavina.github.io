# Go Notes From Small Tools

I keep a tiny Go repo with one file per tool. The rule is simple: solve one
annoying task, ship it, and move on. The payoff is huge because the tools stick
around for years.

## What I like about Go for utilities

- single binary deployments
- fast startup time
- strong standard library
- simple cross-compilation

## The habit

I write down the next command I wish existed, then I build the smallest CLI
that makes it real. The next time I reach for it, I do not have to reinvent the
pipeline again.
